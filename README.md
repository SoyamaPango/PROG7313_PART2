# TCSS – Personal Budget Tracker App

TCSS is a Kotlin-based Android application developed as part of the PROG7313 POE Part 2. It enables users to manage and track their expenses and budget goals in a simple and user-friendly interface. This submission covers the implementation of the core prototype functionalities.

## Features Implemented

•⁠  ⁠User registration and login
•⁠  ⁠Create and manage expense categories (e.g., Food, Transport)
•⁠  ⁠Add expense entries with amount, date, description, and category
•⁠  ⁠Option to attach receipt photos to expenses
•⁠  ⁠Set minimum and maximum monthly budget goals
•⁠  ⁠View all expenses within a user-selectable period
•⁠  ⁠View total spending per category during a selected period
•⁠  ⁠Local data storage using RoomDB
•⁠  ⁠Error handling and input validation for smooth user experience
•⁠  ⁠Version control and automated builds with GitHub Actions

## Technologies Used

•⁠  ⁠Kotlin
•⁠  ⁠Android Studio
•⁠  ⁠RoomDB (local database)
•⁠  ⁠Android Jetpack libraries
•⁠  ⁠GitHub Actions for CI/CD
•⁠  ⁠XML for UI layouts
