# TCSS: Personal Budgeting Application

## Overview
TCSS is a comprehensive personal budgeting application, well-designed to help users keep track of finances with accuracy. TCSS allows users to create budgets, track expenses, and keep a close watch on spending patterns.

## Characteristics

### User Authentication
A secure registration and login system.
- Profile management
- Session management

Dashboard
A thorough analysis of this month's finances.
- Recent transactions view
- Current month budget progress indicator.
- Expense graph visualization

### Budget Planning
Create monthly budgets that distinguish between minimum and maximum spent.
- Review all present budgets thoroughly.
- Tracking budget progress.
- Compare spending against budget maximum

### Tracking Expenses
- Add new expenses with details (amount, category, description)
- View expense history
- Attach receipts/images to expenses
- Classifying expenses
- Detailed expense view

### Financial Analysis
- Monthly expense reports
Detailed breakdown into categories.

## Guidelines for Usage

### Getting Started
1. Begin the application.
2. Log on with your credentials, or register a new account.
3. Upon successful login, you'll be directed to the dashboard

### Navigating Your Finances
1. Navigate to the Budget page using the navigation drawer.
2. Review your existing budgets.
3. To create a new budget:
Press the floating action button "+"
Choose a month, then a year.
- Enter your budget's minimum and maximum amounts.
- Save your budget.

### Tracking Expenses
1. Access the Expenses section from the navigation drawer
2. Review your expense history.
3. To add a new cost:
Press the "+" button or select "Add Expense" from the menu.
- Fill in expense details (amount, category, date, description)
- Optionally attach a receipt image
- Reduce the cost. 
4. To view expense details:
Be aware of all expenses that come your way.
- Review all details, including receipts attached.
- Alternatives for modifying or eliminating the cost.

### Exploring the Dashboard
1. The dashboard provides an overview of your financial situation
2. View recent transactions at a glance.
3. Monitor the progress of this month's budget.
4. Review trends in spending using visualizations.

### Customize your Profile
1. Change profile picture
2. Change name and surname of user
